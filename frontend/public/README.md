# Public Folder

Esta carpeta contiene archivos estáticos que se servirán directamente desde la raíz del sitio.

## Uso

Puedes colocar aquí:
- Imágenes (jpg, png, webp, svg)
- Iconos
- Fuentes
- Otros archivos estáticos

## Acceso

Los archivos en esta carpeta son accesibles desde la raíz de la URL. Por ejemplo:
- `public/logo.png` → `/logo.png`
- `public/images/banner.jpg` → `/images/banner.jpg`

## Ejemplo en código

```jsx
// En un componente React
<img src="/logo.png" alt="Logo" />
```
